## 5. Defect Log & Surgical Resolutions

During initial test execution, three minor defects were caught and resolved:

* **Defect 1:** Multi-word signal `"pick up"` failed in token-splitting word check.
* **Fix:** Replaced split-word set intersection with substring signal searching in `IntentParser._matches_continue_work`.


* **Defect 2:** `AttributeError: property 'readiness' of 'ReadinessTracker' object has no deleter` when using `unittest.mock.patch.object` on a read-only property.
* **Fix:** Set the underlying tracker state directly via `runtime.readiness_tracker._readiness = EcosystemReadiness.READY`.


* **Defect 3:** `ContinuityOutcome.TARGET_UNAVAILABLE` was referenced in test mock, but the actual enum members are `SUCCESS`, `FAILED`, `CANCELLED`, `UNSUPPORTED`, `UNKNOWN`.
* **Fix:** Updated mock expectation to use `ContinuityOutcome.FAILED`.
