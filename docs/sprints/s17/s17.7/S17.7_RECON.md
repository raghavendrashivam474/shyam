## Q8: What prevents S17.6 from working physically today?

No architectural defect. Two integration gaps:
1. **Trust pre-registration**: The surface-driven request hits _verify_trust()
   before any trust relationship exists with the discovered peer.
2. **Discovery timing**: The CLI -c command executes immediately; LAN discovery
   needs a few seconds to find the target node.

## Q9: Blocker classification?

**Configuration + orchestration integration**, not code defects or
architectural gaps. The pipeline is correct; the physical environment
needs trust seeding and discovery warmup before the surface request fires.
