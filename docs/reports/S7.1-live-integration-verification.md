## 4. Anomaly Log & Surgical Fixes

### ANOM-001: Transfer Request Field Format
- **Observed:** Shyam passed {peer_id, artifact_path, artifact_name, is_directory} whereas Gateway required {peer_id, file_paths: list[str]}.
- **Root Cause:** S7 model assumed single artifact abstraction; Gateway accepts multi-file vector TransferPlan.
- **Fix (Case A):** Updated FluxTransferRequest in models.py to use file_paths: list[str]. Adapted client.initiate_transfer() to wrap single paths into [artifact_path].
- **Regression:** 	est_flux_transfer_models, 	est_transfer_lifecycle.

### ANOM-002: Transfer Response peer_id Omission
- **Observed:** Gateway StartTransferResponse returns {transfer_id, status} without peer_id.
- **Root Cause:** Gateway registers peer custody in session pool; peer_id is only returned on GET /transfer/{id} (GatewayTransferInfo).
- **Fix (Case A):** Removed mandatory peer_id requirement from FluxTransferResponse.
- **Regression:** 	est_flux_transfer_models, 	est_flux_provider_delegated_operations.

### ANOM-003: Transfer State Enum Mismatch
- **Observed:** Gateway returns SCREAMING_SNAKE_CASE states (RUNNING, COMPLETED, FAILED, CANCELLED).
- **Root Cause:** Rust Gateway uses #[serde(rename_all = "SCREAMING_SNAKE_CASE")] on TransferStatus.
- **Fix (Case A):** Aligned FluxTransferStatus enum values in models.py.
- **Regression:** 	est_flux_transfer_models, 	est_transfer_lifecycle.

### ANOM-004: Cancel Transfer Response Format
- **Observed:** Gateway returns {transfer_id, cancelled: bool}.
- **Root Cause:** Gateway aborts task handle and returns boolean flag.
- **Fix (Case A):** Updated FluxCancelResponse to {transfer_id: str, cancelled: bool}.
- **Regression:** 	est_flux_transfer_models, 	est_transfer_lifecycle.

### ANOM-005: Peer Summary Timestamp Representation
- **Observed:** Gateway returns last_seen_secs_ago: f64 instead of ISO string.
- **Root Cause:** Gateway measures elapsed duration from monotonic instant.
- **Fix (Case A):** Added last_seen_secs_ago: float | None to FluxPeerInfo.
- **Regression:** 	est_flux_peers_model, 	est_get_peers_and_peer_detail.

### ANOM-006: Connect Response Field Alignment
- **Observed:** Gateway returns {success: bool, peer_id, connected_address, message}. Shyam expected connected: bool.
- **Root Cause:** Field naming divergence between Gateway and early S7 model draft.
- **Fix (Case A):** Added success, connected_address, and message to FluxConnectResponse with backwards-compatible property alias.
- **Regression:** 	est_flux_provider_delegated_operations, 	est_transfer_lifecycle.
